# HRMS Lite

### Lightweight • Modern • Efficient

**HRMS Lite** is a high-performance Human Resource Management System designed with a focus on minimalist aesthetics and professional functionality. It streamlines core HR processes, including employee management and attendance tracking, through a clean and intuitive interface.

---

## ✨ Key Features

- **📊 Dynamic Dashboard**: Instantly visualize personnel trends and daily attendance metrics.
- **👥 Employee Management**: A robust system for maintaining comprehensive employee records.
- **📅 Smart Attendance**: Frictionless attendance marking with advanced filtering and search.
- **⚡ Performance First**: Built on FastAPI and React for near-zero latency and high throughput.
- **🎨 Premium UI**: A professional-grade interface featuring light/dark adaptive themes.

---

## 🛠️ Tech Stack

### Frontend
- **React 19**: Utilizing the latest React features for a modern user experience.
- **Vite**: Providing ultra-fast HMR and optimized production builds.
- **Vanilla CSS**: Bespoke, premium styling with fluid animations.
- **React Router**: Client-side routing for seamless page transitions.

### Backend
- **FastAPI**: A modern, high-performance web framework for building APIs with Python.
- **Motor / MongoDB**: Asynchronous NoSQL data management for high-concurrency environments.
- **Pydantic**: Type-safe data validation and serialization.
- **Uvicorn**: High-speed ASGI server implementation.

## 🚀 Quick Start

### 1. Repository Setup
```bash
git clone https://github.com/Saswat-Kumar-Pradhan/HRMS-Lite.git
cd HRMS-Lite
```

### 2. Backend Initialization
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: `venv\Scripts\activate`
pip install -r requirements.txt
uvicorn main:app --reload
```

### 3. Frontend Initialization
```bash
cd frontend
npm install
npm run dev
```
